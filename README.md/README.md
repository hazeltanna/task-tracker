# Task Tracker

A full-stack task management application built to practice frontend, backend, database integration, REST APIs, and deployment.

## Live Demo

https://task-tracker-nine-psi-88.vercel.app

## Features

- Add tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by All, Active, and Completed
- Task counts
- Persistent data using PostgreSQL
- Responsive UI
- REST API
- Deployed frontend and backend

## Tech Stack

### Frontend
- React
- Vite
- CSS

### Backend
- Node.js
- Express.js
- REST API

### Database
- PostgreSQL

### Deployment
- Vercel — Frontend
- Render — Backend & Database
